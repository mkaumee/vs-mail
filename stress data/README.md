# Stress inbox

Awkward cases the organizers' bundle does not contain. Written for
this project; `sample data/` is theirs and is never edited.

Each email answers one question. `expectations.json` records the
expected outcome and why, so `scripts/check_stress.py` can check a
run rather than leaving it to be eyeballed.

A few are marked ARGUABLE — they are here because the right answer
is genuinely not obvious, and those are the ones worth arguing about.
